# Single Cell / Single Nuclei Tissue Type 권장 가이드

아래 표는 tissue type별로 Single Nuclei Suspension 또는 Single Cell Suspension 권장 여부를 정리한 참고 자료입니다.

## 적용 원칙
- Single Cell 서비스 안내 시 본 문서를 우선 참고합니다.
- 기존 single cell manual과 충돌하는 내용이 있는 경우, 본 문서 기준을 우선 적용합니다.
- 최종 진행 전에는 샘플 상태(신선도/보관), 목표 세포군, 분석 목적(예: immune profiling, VDJ 포함 여부)을 함께 확인합니다.
