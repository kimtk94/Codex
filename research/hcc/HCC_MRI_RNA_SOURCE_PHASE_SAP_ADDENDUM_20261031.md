# HCC MRI × RNA — SAP v1 source-image correction addendum (before any RNA association)

**Amendment date:** 2026-10-31 KST. Original [pre-locked SAP v1](HCC_MRI_RNA_PREOUTCOME_HALLMARK_SAP_V1.md) remains immutable. This document is an **imaging-source provenance correction**, not a new biological hypothesis.

## Rationale independent of MRI–RNA outcomes

- LiverHccSeg v1.1 official data description (https://zenodo.org/records/8179129) documents tumor segmentation masks applied to arterial (`art`) and arterial-registered phase images, including `art_pv` (registered PV). Original analysis used unregistered `pv` while source headers happened to match the ROI.
- An independent 14-case phase audit [#41188630515](https://github.com/kimtk94/Codex/actions/runs/41188630515) established that all `art_pv` source NIfTIs align with fixed masks after exact voxel axis orientation changes, to ≤0.5 mm header geometry tolerance, with no interpolation at the audit step.
- [Fourteen-case source comparison #41191599451](https://github.com/kimtk94/Codex/actions/runs/41191599451) extracted all ten pre-existing MRI features from 14 patients × 2 readers × two PV arms, without accessing MRI–RNA association statistics. Official `art_pv` source differences are substantial for GLCM Contrast; **no molecular effect or pathway association was tested**.

## Prospective canonical imaging source

1. **Registered source condition:** for any eventual permitted image–RNA test, `art_pv.nii.gz` after nibabel voxel-axis permutation/flip into the original selected tumor mask's physical reference frame is the canonical PV MRI arm. Do not recompute vendor's nonrigid registration or silently overwrite source files. Declare exact original source file path and SHA, NIfTI qform/sform, fixed tumor index and reader, `PyRadiomics 3.1.0`, `binWidth=25`, `normalize=True`, `normalizeScale=100`, `voxelArrayShift=0`, `resampledPixelSpacing=None`, `correctMask=False`, `minimumROIDimensions=2`, `preCrop=True` and explicit `geometryTolerance=0.5mm` (header roundoff only).
2. **Historical reference condition:** original `pv.nii.gz` outputs and previously saved 14-case original-PV ICC/3-mm/binWidth factorials remain historical technical evidence and source-robustness sensitivity; they must **not** substitute for registered PV MRI signals in the canonical arm.
3. **No patient reselection:** the same 14 fixed source-available cases remain technical candidates. The A10Y representative tumor **tumor3** is unchanged. Clinical eligibility must be adjudicated patient by patient by authoritative source MRI-before-therapy and MRI index tumor to GDC primary-tumor RNA tissue correspondence. Missing evidence is `NOT_ASSESSED`, **not eligible and not automatically excluded**. Independent anatomical registered-source ROI approval remains mandatory.
4. **No outcome peeking:** the original three imaging features are unchanged: `original_firstorder_Entropy`, `original_glcm_Contrast`, `original_firstorder_InterquartileRange`. The original four MSigDB 2025.1.Hs Hallmarks are unchanged (Hypoxia, Angiogenesis, EMT, Glycolysis). Exactly **12** primary MRI–RNA tests, original BH-FDR across all twelve, original permuted Spearman framework, regardless of image-source QC findings. **Do not drop GLCM Contrast from the locked family** simply because of source sensitivity; add its instability as an interpretation limitation. Do not execute any outcome comparisons until eligibility gates are met.
5. **Reader use / pseudoreplication:** each patient is one unit. Two expert reader ROI features are repeated measures, not 28 independent MRI–RNA paired samples. Future association must lock how two reader measurements collapse (e.g. mean) before any testing; report reader-specific outcome-blind ICC and sensitivity. If a new averaging convention is not already specified in original SAP v1, mark **NOT LOCKED** and require prospective specification before any association.
6. **Robustness:** after valid eligibility, report effect sensitivity to raw-PV source as explicitly subordinate technical alternative without selecting whichever arm gives the smaller p-value. Recompute source-registered binWidth/voxel-spacing sensitivity (original factorial was on raw PV) and check source-space registration quantitatively, independent of biology.
7. **GO gate:** clinically eligible independent paired patients must satisfy original SAP minimum n and anatomical/chronology/lineage gates. If not, **do not run 12 associations**, regardless of successful technical extraction. No statements about predictive accuracy, immune biology, treatment response or survival without external clinical evidence.

**Clinical snapshot:** 14 MRI/RNA ID overlaps are only technical candidates, all per-patient eligibility unresolved. This amendment does not change original biological hypothesis family, gene universe, exposure outcome definition, multiple-testing plan or claim ceiling **S0**.
